# TP7 - React Router y Blob

Aplicación realizada con Create React App y React Router. La barra de navegación
permite abrir Inicio, proyectoBlob, Acerca de nosotros y Contacto. En proyectoBlob
se puede editar un texto, crear un `Blob`, descargarlo como archivo y obtener
una porción con el método `slice()`.

## Cómo ejecutar el proyecto

Desde una terminal ubicada en esta carpeta:

```bash
npm install
npm start
```

La aplicación se abrirá en [http://localhost:3000](http://localhost:3000).

## Scripts disponibles

- `npm start`: inicia el servidor de desarrollo.
- `npm test`: ejecuta las pruebas.
- `npm run build`: genera la versión de producción.
